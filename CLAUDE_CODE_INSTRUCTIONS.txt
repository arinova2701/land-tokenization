====================================================================
WHAT THIS PROJECT IS
====================================================================

A smart contract system that authenticates court-issued freeze orders
on tokenized land parcels. ERC-3643 defines HOW to freeze a property
token but not WHO is authorized to trigger it. This project fills
that gap with on-chain signature verification.

When an Indian court issues an interim injunction to freeze a
disputed property, the judge digitally signs the order. The signed
order is submitted to the CourtKeyRegistry smart contract, which:

1. Checks order expiry (not stale)
2. Checks replay protection (not submitted before)
3. Recovers signer identity via ECDSA from the signature
4. Checks signer against a registry of authorized judicial signers
5. Checks signer's key temporal validity (not expired/revoked)
6. Checks territorial jurisdiction (judge's court must cover the
   property's location in the court hierarchy)

Only if ALL checks pass does the property token get frozen.

====================================================================
IMPORTANT NOTES
====================================================================

- The contract uses OpenZeppelin v5.x which requires evmVersion:
  "cancun" due to mcopy instruction in Bytes.sol
- Frontend loads ethers.js from CDN:
  https://cdn.jsdelivr.net/npm/ethers@6.13.1/dist/ethers.umd.min.js
- The frontend uses human-readable ABI strings, not JSON ABI
- Deploy script writes public/config.json which the frontend reads
- Court names with commas break Remix's input parser (use no commas)
- Hardhat accounts are deterministic — same addresses every time
- The registerJudge function now takes 6 params:
  (address, string, uint256, uint256, uint8, bytes32)
  The extra two are courtLevel and territoryCode
- Territory hierarchy: districts have parent states.
  A High Court judge registered under "tamil_nadu" can freeze
  property in vellore or chennai (child territories).
  A District Court judge registered under "vellore" can only
  freeze vellore property, not chennai.
